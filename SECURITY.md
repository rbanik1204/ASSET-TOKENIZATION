# Security

🚨 **DO NOT DEPLOY TO MAINNET** until:
- All critical blockers are resolved
- A real external audit is complete
- Testnet deployment has been validated

## Audit handoff
See [security/audit-package/README.md](security/audit-package/README.md).

## Deploy safety
- Use testnets (Sepolia) only until an external audit is complete.
- Firebase Hosting SSR deployments require enabling Cloud APIs; see [DEPLOY_FIREBASE_SSR.md](DEPLOY_FIREBASE_SSR.md).

## Reporting
If you discover a security issue, do not open a public GitHub issue. Use a private channel.
